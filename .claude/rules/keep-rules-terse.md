# Keep Rules Terse

A rule's tokens are a cost paid every session, and length shifts weight: words spent here dilute every other rule.

Write the smallest rule that changes behavior. State it once and stop, without explaining how it came about, restating it at the end, or insisting on how important it is. Add an example only if the rule is unclear without one.
